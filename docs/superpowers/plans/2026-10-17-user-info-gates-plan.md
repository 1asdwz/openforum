# 用户信息与板块门槛实施计划

- 日期：2026-10-17
- 规格：[2026-10-17-user-info-gates-design.md](../specs/2026-10-17-user-info-gates-design.md)
- 原型：[2026-10-17-user-info-gates.html](../mockups/2026-10-17-user-info-gates.html)
- 范围：P1（信息模型、资料中心、双门槛、拦截与隐私收敛）

## 任务

### 1. 后端基础设施

- [ ] `error.rs` 支持带 `data` 的业务错误。
- [ ] 新增 `info.rs`：字段目录、信息项值类型、年龄计算、职业/学历枚举。
- [ ] 新增 `gate.rs`：规则 JSON 结构、解析、条件判定、缺失原因、豁免。
- [ ] 新增 `migrate.rs`：建表、字段种子、旧规则转换、旧认证回填。
- [ ] `models.rs`：`SubForum` 增加规则字段；新增 `UserInfo`、`InfoField`。
- [ ] `main.rs` 启动时执行迁移。

### 2. 后端接口

- [ ] `GET /info/fields`、`GET /info/me`、`PUT /info/me/:fieldKey`。
- [ ] 论坛创建/更新接收 `browseRule` / `operateRule`，详情回显。
- [ ] 浏览拦截：板块详情、成员、自定义页、帖子列表/详情、评论树、首页信息流过滤。
- [ ] 操作拦截：发帖、评论、点赞、投票。
- [ ] 认证类型扩展与审核通过后联动写入 `user_info`。
- [ ] 公开用户资料移除认证徽章。

### 3. 前端

- [ ] `types` / `api` 增加信息项、规则与错误 `data` 类型。
- [ ] 新增 `/profile` 资料与认证页（分组资料卡 + 认证抽屉）。
- [ ] 新增 `GateRuleEditor.vue`（条件行、算子、值控件、认证等级、摘要、模板）。
- [ ] 创建板块与管理板块接入构建器。
- [ ] 板块页/帖子页 403 拦截提示；未登录跳登录。
- [ ] 左侧导航加入「资料与认证」；公开资料页移除徽章。

### 4. 验证

- [ ] `cargo check --release`。
- [ ] `npm run build`。
- [ ] 门槛引擎单元测试：算子、多选 OR、等级、年龄、缺失原因。
- [ ] 迁移幂等：连续执行两次无重复。
- [ ] 线上冒烟：资料填写、创建板块设门槛、另一账号验证拦截。

## 依赖与顺序

1. 后端基础设施 → 后端接口 → 前端（按规格契约并行开发）。
2. 迁移必须先于新接口上线；旧规则保持回退。
3. 前端完成后统一构建并部署 Rust 与前端。

## 风险

- 启动迁移涉及线上表结构，先在本地/预发验证幂等性。
- 首页信息流过滤会改变分页总数，需与旧行为对比确认。
- 认证审核联动写入必须与审核事务保持一致，避免半更新。
