板块门槛设置 · 自然语言

解析结果始终可手动微调
性别 = 男 年龄 25–40 城市 ∈ {上海, 杭州} 学历 ≥ 本科 职业 ∈ {互联网/产品, 互联网/研发} 操作：实名 ≥ 高
浏览门槛：性别 = 男，且 年龄 25–40，且 城市 ∈ {上海, 杭州}，且 学历 ≥ 本科，且 职业 ∈ {互联网/产品, 互联网/研发}。
自然语言可能存在歧义（例如「本科以上」是否含本科、「产品/研发」是否限互联网行业），必须逐条确认后才能保存。

两种写法的差异

向导式填写
首次填写体验好，但修改单项要重新进入对应步骤。
自然语言门槛
配置快，但依赖解析质量；复杂条件仍需手动构建器兜底。
建议
资料填写采用「资料卡 + 单项抽屉」，门槛采用「条件构建器 + 可选自然语言快捷输入」。
